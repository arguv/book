First-Time Git Setup

Your Identity

The first thing you should do when you install Git is to set your user name and e-mail address. This is important because every Git commit uses this information, and it is immutably baked into the commits you start creating: 

				$ git config --global user.name "John Doe"
				$ git config --global user.email johndoe@example.com
			
			git init
			git add *
			git commit -m "My initial commit message"
			git remote add origin git@example.com:my_project.git
			git push -u origin master
			
				git reset --hard HEAD~1
The HEAD~1 means the commit before head. Or, you could look at the output of git log, find the commit id of the commit you want to back up to, and then do this: 
				git reset --hard
If you already pushed it, you will need to do a force push to get rid of it... 
				git push origin HEAD --force
Category Command Description
Setup & Init git init Initialize repo
git clone [url] Clone repo from URL
Stage & Snapshot git status Show changed files
git add [file] Add file to staging
git reset [file] Unstage file
git diff --staged Show staged changes
git commit -m "[message]" Commit with message
Branches git branch List branches
git checkout -b [name] Create and switch branch
git log Show commit history
Share & Update git remote add [ref] [url] Add remote repo
git push [alias] [branch] Push to remote
git pull Fetch and merge
Temporary Commits git stash Stash changes
git stash pop Apply stash
git stash drop Discard stash
Rewrite History git rebase [branch] Rebase current branch
git rebase -i HEAD~<n> Interactive rebase
git reset --hard [commit] Reset to commit
Inspect & Compare git log branchB..branchA Show unique commits in branchA
git diff branchB...branchA Diff between branches
git show [SHA] Show commit
Ignoring Patterns git config --global core.excludesfile [file] Ignore files
