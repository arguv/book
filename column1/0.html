Abstraction

Abstraction means: Hiding the complex implementation details and exposing only what's essential to the outside world.
Abstraction = hide how something is done, expose what it does.
Abstraction is achieved mainly through abstract classes and interfaces.
abstract class Shape {
    abstract public function area(): float;

    public function describe() {
        echo "This shape has an area of " . $this->area() . "\n";
    }
}

class Circle extends Shape {
    public function __construct(private float $r) {}

    public function area(): float {
        return M_PI * $this->r ** 2;
    }
}

class Square extends Shape {
    public function __construct(private float $side) {}

    public function area(): float {
        return $this->side ** 2;
    }
}

$c = new Circle(2);
$c->describe(); // This shape has an area of 12.566...

⚠️ Abstract Classes

  • ✅ Can mix abstract methods (no body) with concrete methods (with body)
  • ✅ Child classes must implement all abstract methods
  • ✅ Can have properties, constructors, constants.
  • ❌ Cannot be instantiated directly.
  • Abstract Class - "is-a" (Circle is a Shape)

⚠️ Interfaces

  • ✅ interface is pure abstraction — only method signatures, no implementation.
  • ✅ A class can implement many interfaces.
  • ✅ All methods are implicitly public and abstract
  • ❌ No properties, no implementation (until PHP 8.0+...)
  • Interface - "can-do" (Stripe can act as a PaymentGateway)

⚠️ PHP Version Notes

  • PHP 8.0+: Interfaces can have static methods and (since 8.3) constants with types.
  • Traits offer another form of code reuse, but they're not abstraction — they're implementation sharing.
  • Enums (PHP 8.1) and readonly properties (8.1/8.2) pair nicely with abstraction patterns.
interface PaymentGateway {
    public function pay(float $amount): bool;
    public function refund(string $transactionId): bool;
}

class StripeGateway implements PaymentGateway {
    public function pay(float $amount): bool {
        // Stripe-specific logic
        return true;
    }

    public function refund(string $transactionId): bool {
        // Stripe-specific logic
        return true;
    }
}

class PayPalGateway implements PaymentGateway {
    public function pay(float $amount): bool {
        // PayPal-specific logic
        return true;
    }

    public function refund(string $transactionId): bool {
        // PayPal-specific logic
        return true;
    }
