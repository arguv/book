Day 1 — Python Syntax and Data Structures

Learn Python syntax through practical examples and comparisons with PHP.

Goal: Understand Python's core types, control flow, collections and comprehensions, then build a small support-ticket filtering program. Estimated time: 3–4 hours.

Since you already know PHP, focus on Python conventions instead of translating PHP patterns literally. Use snake_case, four-space indentation and readable code.
1. Variables, types, and expressions

Python variables do not start with $, and statements usually do not need semicolons. Python is dynamically typed and supports optional type hints.

PHP vs Python

PHP 
$name = "John";
$age = 30;
$isActive = true;
$salary = null;
Python 
name = "John"
age = 30
is_active = True
salary = None

Basic data types

Python PHP equivalent Example
str string "Hello"
int int 42
float float 3.14
bool bool True, False
NoneType null None 
name = "John"
age = 30
salary = 2500.50
is_active = True
department = None

print(type(name))        # <class 'str'>
print(type(age))         # <class 'int'>
print(type(salary))      # <class 'float'>
print(type(is_active))   # <class 'bool'>
print(type(department))  # <class 'NoneType'>

Expressions and operators

a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.333...
print(a // b)  # 3 (floor division)
print(a % b)   # 1 (remainder)
print(a ** b)  # 1000 (exponentiation)

print(10 == "10")  # False
print(10 != 5)     # True

Unlike PHP, Python has no === operator. Python's == does not perform PHP-style numeric-string coercion. Use is None when checking for None.

Strings and f-strings

PHP 
$name = "John";
echo "Hello, $name";
Python 
name = "John"
print(f"Hello, {name}")
price = 100
quantity = 3
print(f"Total: {price * quantity}")  # Total: 300

Practice: Create five variables with different types, print their types, and build an f-string containing two expressions.

2. Conditions and loops

Python uses indentation rather than braces to define code blocks. Put a colon (:) after if, elif, else, for and while statements.

Conditions

status = "open"
priority = "high"

if status == "open" and priority == "high":
    print("Urgent ticket")
elif status == "open":
    print("Normal open ticket")
else:
    print("Ticket is not open")

Python uses and, or and not instead of PHP's &&, || and !.

For loops

names = ["Anna", "John", "David"]
for name in names:
    print(name)

for i in range(5):
    print(i)  # 0 through 4

for index, name in enumerate(names):
    print(index, name)

A Python for loop is often similar to PHP's foreach. range(5) stops before 5. enumerate() gives the index and item together.

While loops

count = 0
while count < 3:
    print(count)
    count += 1

break exits a loop; continue skips to the next iteration.

Practice: Print numbers 0–9, then print only the even numbers. Try the same exercise using while.

3. Lists, tuples, dictionaries, and sets

A PHP array can represent both a sequential list and an associative map. Python uses distinct collection types with different behaviors.

Type Example Properties Common use
List [1, 2, 3] Ordered, mutable, duplicates allowed Sequence of tickets
Tuple (1, 2, 3) Ordered, immutable, duplicates allowed Fixed coordinates
Dictionary {"id": 1} Insertion-ordered key/value mapping, mutable Ticket data / JSON objects
Set {1, 2, 3} Unique values, unordered Allowed statuses

Lists

tickets = [101, 102, 103]
tickets.append(104)
tickets.remove(102)
print(tickets)       # [101, 103, 104]
print(tickets[0])    # 101
print(tickets[-1])   # 104 (last item)
print(tickets[0:2])  # [101, 103]
print(len(tickets))  # 3

Tuples

coordinates = (40.18, 44.51)
print(coordinates[0])
# coordinates[0] = 50  # TypeError: immutable

Dictionaries: PHP associative arrays vs Python dict

PHP 
$ticket = [
    "id" => 101,
    "status" => "open",
    "priority" => "high"
];
Python 
ticket = {
    "id": 101,
    "status": "open",
    "priority": "high",
}
print(ticket["status"])   # open
ticket["status"] = "closed"
print(ticket.get("assigned_to"))                # None
print(ticket.get("assigned_to", "Unassigned"))  # Unassigned

for key, value in ticket.items():
    print(key, value)
ticket["assigned_to"] raises KeyError if the key is missing; ticket.get("assigned_to") returns None by default. This distinction matters when processing API responses.

Sets

statuses = ["open", "closed", "open", "pending"]
unique_statuses = set(statuses)
print(unique_statuses)  # Three unique statuses; order varies

allowed_statuses = {"open", "closed", "pending"}
print("open" in allowed_statuses)  # True

Practice: Create a list of three ticket dictionaries, change one ticket's status, and find the set of unique statuses.

4. Comprehensions

A comprehension builds a new collection from an iterable, optionally filtering items. It can replace some uses of PHP's array_filter() and array_map(), but readability comes first.

Regular loop

numbers = [1, 2, 3, 4, 5]
even_numbers = []
for number in numbers:
    if number % 2 == 0:
        even_numbers.append(number)

List comprehension

even_numbers = [
    number for number in numbers
    if number % 2 == 0
]
print(even_numbers)  # [2, 4]

Pattern: [expression for item in iterable if condition]

Dictionary comprehension

tickets = [
    {"id": 101, "status": "open"},
    {"id": 102, "status": "closed"},
]
ticket_by_id = {
    ticket["id"]: ticket
    for ticket in tickets
}
print(ticket_by_id[101])

Practice: Build a list of squared numbers from 1 to 10, then keep only the squares of even numbers.

5. Practical exercise — Support tickets

Create a file named day1_tickets.py. Each ticket should have an integer id, string title, valid status (open, closed, pending) and valid priority (low, medium, high).

Starter code

tickets = [
    {"id": 101, "title": "Login issue", "status": "open", "priority": "high"},
    {"id": 102, "title": "Payment failed", "status": "closed", "priority": "high"},
    {"id": 103, "title": "Email not received", "status": "pending", "priority": "medium"},
    {"id": 104, "title": "API timeout", "status": "open", "priority": "high"},
    {"id": 105, "title": "Update profile", "status": "closed", "priority": "low"},
]

# TODO:
# 1. Print all ticket titles.
# 2. Filter tickets with status "open".
# 3. Count open tickets.
# 4. Find tickets with both status "open" and priority "high".
# 5. Test a status with no matches ("cancelled").
# 6. Handle a ticket with a missing status.
# 7. Reject a ticket whose status is an integer.

Hints

open_tickets = [
    ticket for ticket in tickets
    if ticket["status"] == "open"
]

status = ticket.get("status")  # Safely access a possibly missing key
if not isinstance(status, str):
    print("Invalid status")

allowed_statuses = {"open", "closed", "pending"}
if status not in allowed_statuses:
    print("Unsupported status")
Edge cases: A no-match filter should return an empty list, not an error. A missing status and a wrong-type status should be detected explicitly. A string such as "unknown" is also invalid even though its type is correct.
