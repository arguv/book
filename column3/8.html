SQL

There are many popular SQL databases including SQLite, MySQL, Postgres, Oracle and Microsoft SQL Server. All of them support the common SQL language standard, but each implementation can differ in the additional features and storage types it supports. A relational database represents a collection of related (two-dimensional) tables. Each of the tables are similar to an Excel spreadsheet, with a fixed number of named columns (the attributes or properties of the table) and any number of rows of data.
All major SQL databases — like SQLite, MySQL, PostgreSQL, Oracle, and Microsoft SQL Server — use the same core SQL standard (things like SELECT, INSERT, UPDATE, DELETE, JOIN, etc.), but they differ in many important details and extra features.
Data Types
  • MySQL has TINYINT, ENUM, and SET
  • PostgreSQL supports ARRAY, JSONB, and HSTORE
  • Oracle has CLOB and BLOB for large data
  • SQL Server uses NVARCHAR(MAX) instead of TEXT
  • SQLite is simpler — it uses dynamic typing (no strict column types)
Storage Engines and Architecture
  • MySQL supports different storage engines (like InnoDB, MyISAM).
  • PostgreSQL uses a single powerful engine with advanced features (ACID, MVCC).
  • Oracle and SQL Server have very complex internal engines for performance, clustering, and transactions.
  • SQLite is file-based — it stores everything in one file, not a server.
Concurrency and Transactions - Handling of simultaneous reads/writes differs:
  • PostgreSQL and Oracle use MVCC (Multi-Version Concurrency Control) — very good for heavy traffic.
  • MySQL (InnoDB) also uses MVCC but in a simpler form.
  • SQLite allows only one writer at a time (not great for high concurrency).
Performance and Use Cases
  • SQLite → small apps, mobile, testing, local tools
  • MySQL → web apps (WordPress, etc.), high read workloads
  • PostgreSQL → complex queries, analytics, enterprise-grade reliability
  • Oracle → large enterprises, banking, mission-critical apps
  • SQL Server → enterprise/business apps (especially Windows environments)
