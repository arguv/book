PYTHON СЛОВАРИ (DICT)

Что такое словарь (dict)?

Словарь (dict) - это изменяемая коллекция пар "ключ-значение" в Python. Ключи должны быть уникальными и хешируемыми, значения могут быть любого типа. Словари оптимизированы для быстрого получения значения по ключу.

Основные характеристики словарей:
  • Неупорядоченность (до Python 3.7, с 3.7+ сохраняют порядок добавления)
  • Изменяемость (можно добавлять, изменять, удалять пары ключ-значение)
  • Уникальность ключей (каждый ключ может встречаться только один раз)
  • Произвольность значений (значения могут быть любого типа)
  • Хешируемость ключей (ключи должны быть неизменяемыми)
Пример словаря:
# Пример словаря с разными типами данных
my_dict = {
    "name": "Alice",
    "age": 25,
    "is_student": True,
    "grades": [85, 90, 88],
    "address": {"city": "Moscow", "street": "Tverskaya"}

print(my_dict)
print(type(my_dict))  # <class 'dict'>

1. Прямое создание с фигурными скобками
# Пустой словарь
empty_dict = {}
empty_dict = dict()

# Словарь с элементами
person = {
    "name": "Alice",
    "age": 25,
    "city": "Moscow"
}

# Словарь с разными типами ключей (ключи должны быть хешируемыми)
mixed_keys = {
    "string_key": "value1",
    123: "value2",           # целое число как ключ
    3.14: "value3",          # float как ключ
    (1, 2, 3): "value4",     # кортеж как ключ
    True: "value5",          # булево значение как ключ
    # [1, 2]: "value6"      # ОШИБКА: список не может быть ключом
    # {"key": "value"}: "v" # ОШИБКА: словарь не может быть ключом
}

print(f"person: {person}")
print(f"mixed_keys: {mixed_keys}")
2. Использование конструктора dict()

3. Генераторы словарей (Dict Comprehensions)
# Создание словаря квадратов
squares = {x: x**2 for x in range(1, 6)}
print(f"Квадраты: {squares}")  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# С условием (фильтрацией)
even_squares = {x: x**2 for x in range(1, 11) if x % 2 == 0}
print(f"Квадраты четных: {even_squares}")  # {2: 4, 4: 16, 6: 36, 8: 64, 10: 100}

# Преобразование списка в словарь
words = ["apple", "banana", "cherry"]
word_lengths = {word: len(word) for word in words}
print(f"Длины слов: {word_lengths}")  # {'apple': 5, 'banana': 6, 'cherry': 6}

# Инвертирование словаря (ключи ↔ значения)
original = {"a": 1, "b": 2, "c": 3}
inverted = {value: key for key, value in original.items()}
print(f"Инвертированный: {inverted}")  # {1: 'a', 2: 'b', 3: 'c'}

# Словарь с условием в значении
numbers = {x: "четное" if x % 2 == 0 else "нечетное" for x in range(1, 6)}
print(f"Четность: {numbers}")
Генераторы словарей - это питоничный и эффективный способ создания словарей на основе итерируемых объектов.
Доступ к элементам
Получение значений по ключу
person = {
    "name": "Alice",
    "age": 25,
    "city": "Moscow",
    "hobbies": ["reading", "swimming"]
}

# 1. Прямой доступ через квадратные скобки
print(f"Имя: {person['name']}")  # Alice
print(f"Возраст: {person['age']}")  # 25

# 2. Доступ через get() (безопасный способ)
print(f"Город: {person.get('city')}")  # Moscow
print(f"Страна: {person.get('country')}")  # None (ключ не существует)
print(f"Страна с default: {person.get('country', 'Russia')}")  # Russia

# 3. Доступ к вложенным словарям
person["address"] = {"city": "Moscow", "street": "Tverskaya"}
print(f"Улица: {person['address']['street']}")  # Tverskaya

# 4. Доступ к элементам списка внутри словаря
print(f"Первое хобби: {person['hobbies'][0]}")  # reading

# ОШИБКА при доступе к несуществующему ключу через []
try:
    print(person['country'])  # KeyError: 'country'
except KeyError as e:
    print(f"Ошибка: ключ '{e}' не найден")

# Проверка наличия ключа
if "name" in person:
    print(f"Ключ 'name' существует со значением: {person['name']}")

if "country" not in person:
    print("Ключ 'country' не существует")

person = {"name": "Alice", "age": 25}

Удаление элементов
Удаление из словаря
person = {
    "name": "Alice",
    "age": 25,
    "city": "Moscow",
    "country": "Russia",
    "job": "Engineer"
}

# 1. pop() - удаляет ключ и возвращает значение
age = person.pop("age")
print(f"Удален возраст: {age}")
print(f"После pop('age'): {person}")

# pop() с значением по умолчанию (если ключ не существует)
salary = person.pop("salary", 0)  # Вернет 0, т.к. ключа нет
print(f"Попытка удалить несуществующий ключ: {salary}")

# 2. popitem() - удаляет и возвращает последнюю пару (Python 3.7+ сохраняет порядок)
key, value = person.popitem()
print(f"Удалена последняя пара: {key} = {value}")
print(f"После popitem(): {person}")

# 3. del - удаление оператором
del person["city"]
print(f"После del ['city']: {person}")

# 4. clear() - очистка всего словаря
person.clear()
print(f"После clear(): {person}")  # {}

# 5. Удаление несуществующего ключа вызывает ошибку
try:
    del person["nonexistent"]  # KeyError
except KeyError as e:
    print(f"Ошибка при удалении: ключ '{e}' не найден")
Методы словарей
Метод Описание Пример
keys() Возвращает представление ключей dict.keys()
values() Возвращает представление значений dict.values()
items() Возвращает представление пар (ключ, значение) dict.items()
get(key, default) Возвращает значение для ключа или default dict.get('x', 0)
setdefault(key, default) Возвращает значение, если ключ есть, иначе устанавливает default dict.setdefault('x', 0)
update([other]) Обновляет словарь элементами из other dict.update({'x': 1})
pop(key[, default]) Удаляет ключ и возвращает значение dict.pop('x')
popitem() Удаляет и возвращает последнюю пару dict.popitem()
clear() Удаляет все элементы dict.clear()
copy() Возвращает поверхностную копию dict.copy()
Примеры использования методов
person = {
    "name": "Alice",
    "age": 25,
    "city": "Moscow",
    "country": "Russia"
}

# keys() - получение ключей
print(f"Ключи: {list(person.keys())}")  # ['name', 'age', 'city', 'country']

# values() - получение значений
print(f"Значения: {list(person.values())}")  # ['Alice', 25, 'Moscow', 'Russia']

# items() - получение пар ключ-значение
print(f"Пары: {list(person.items())}")
# [('name', 'Alice'), ('age', 25), ('city', 'Moscow'), ('country', 'Russia')]

# get() - безопасное получение значения
print(f"Имя: {person.get('name')}")      # Alice
print(f"Зарплата: {person.get('salary', 0)}")  # 0 (значение по умолчанию)

# setdefault() - установка значения по умолчанию
person.setdefault("language", "Russian")
print(f"После setdefault: {person}")

# copy() - создание копии
person_copy = person.copy()
person_copy["age"] = 30
print(f"Оригинал: {person['age']}")      # 25
print(f"Копия: {person_copy['age']}")    # 30

# Проверка наличия ключей
print(f"Есть ли ключ 'name'? {'name' in person}")  # True
print(f"Есть ли ключ 'salary'? {'salary' in person}")  # False

Различные способы обхода словаря
person = {
    "name": "Alice",
    "age": 25,
    "city": "Moscow",
    "country": "Russia"

print("1. Итерация по ключам:")
for key in person:
    print(f"Ключ: {key}")

print("\n2. Итерация по ключам через .keys():")
for key in person.keys():
    print(f"Ключ: {key}")

print("\n3. Итерация по значениям:")
for value in person.values():
    print(f"Значение: {value}")

print("\n4. Итерация по парам ключ-значение:")
for key, value in person.items():
    print(f"{key}: {value}")

for i, (key, value) in enumerate(person.items()):
    print(f"{i}. {key}: {value}")

print("\n6. Итерация с условием:")
for key, value in person.items():
    if isinstance(value, str):
        print(f"Строковое поле {key}: {value}")

dict1 = {"a": 1, "b": 2}

for key in set(dict1) | set(dict2):
    print(f"{key}: dict1={dict1.get(key)}, dict2={dict2.get(key)}")

print("\n8. Преобразование в список при итерации:")

scores = {

from collections import defaultdict

# defaultdict автоматически создает значения для отсутствующих ключей
# 1. Со списком по умолчанию
list_dict = defaultdict(list)
list_dict['fruits'].append('apple')
list_dict['fruits'].append('banana')
list_dict['vegetables'].append('carrot')

# 2. С целым числом по умолчанию
int_dict = defaultdict(int)
words = ['apple', 'banana', 'apple', 'orange', 'banana', 'apple']
for word in words:
    int_dict[word] += 1
print(f"Подсчет слов: {dict(int_dict)}")

# 3. С пользовательской функцией по умолчанию
def default_factory():
    return "Неизвестное значение"

custom_dict = defaultdict(default_factory)
print(f"Значение для несуществующего ключа: {custom_dict['unknown']}")

# Сравнение с обычным словарем
# Без defaultdict:
normal_dict = {}

    if word not in normal_dict:

3. Counter
from collections import Counter

# Counter - специальный словарь для подсчета элементов
words = ['apple', 'banana', 'apple', 'orange', 'banana', 'apple', 'apple']

# Создание Counter
word_counter = Counter(words)
print(f"Подсчет слов: {word_counter}")
print(f"Сколько раз 'apple'? {word_counter['apple']}")
print(f"Сколько раз 'grape'? {word_counter['grape']}")  # 0 (не вызывает ошибку)

# Методы Counter
print(f"\n3 самых частых: {word_counter.most_common(3)}")
print(f"Уникальные слова: {list(word_counter.keys())}")

# Арифметические операции
counter1 = Counter({'a': 3, 'b': 2, 'c': 1})
counter2 = Counter({'a': 1, 'b': 2, 'd': 3})

print(f"\nСложение: {counter1 + counter2}")
print(f"Вычитание: {counter1 - counter2}")
print(f"Пересечение: {counter1 & counter2}")
print(f"Объединение: {counter1 | counter2}")

# Практический пример: анализ текста
text = "python is great python is awesome python is powerful"
words = text.split()
text_counter = Counter(words)
print(f"\nАнализ текста: {text_counter.most_common()}")

# 4. Объединение с сохранением всех значений для повторяющихся ключей
from collections import defaultdict

dict1 = {'a': [1], 'b': [2]}
dict2 = {'b': [20], 'c': [3]}
dict3 = {'a': [10], 'c': [30]}

# Создаем defaultdict с списками
merged_with_lists = defaultdict(list)

# Добавляем все значения
for d in [dict1, dict2, dict3]:
    for key, value in d.items():
        if isinstance(value, list):
            merged_with_lists[key].extend(value)
        else:
            merged_with_lists[key].append(value)

print(f"\n4. Сохраняем все значения: {dict(merged_with_lists)}")

# 5. Объединение с пользовательской логикой для конфликтующих ключей
def merge_dicts_custom(*dicts, resolve=lambda x, y: y):
    """Объединение словарей с функцией разрешения конфликтов"""
    result = {}
    for d in dicts:
        for key, value in d.items():
            if key in result:
                result[key] = resolve(result[key], value)
            else:
                result[key] = value
    return result

# При конфликте берем сумму значений
merged_sum = merge_dicts_custom(dict1, dict2, dict3, resolve=lambda x, y: x + y)
print(f"\n5. Суммируем конфликтующие значения: {merged_sum}")

# При конфликте берем максимальное значение
merged_max = merge_dicts_custom(
    {'a': 1, 'b': 5},
    {'a': 3, 'b': 2},
    resolve=max
)

Производительность операций
Операция Временная сложность Примечание
Получение значения по ключу O(1) Быстрая операция (хеш-таблица)
Добавление элемента O(1) В среднем O(1), может быть O(n) при рехешировании
Удаление элемента O(1) Быстрая операция
Проверка наличия ключа O(1) Основное преимущество словарей
Итерация по всем элементам O(n) Нужно пройти все элементы
Копирование (copy()) O(n) Нужно скопировать все элементы
Объединение словарей O(n+m) Зависит от размеров обоих словарей
Сортировка O(n log n) Зависит от алгоритма сортировки
Словари оптимизированы для поиска по ключу. Используйте их, когда нужен быстрый доступ к данным по уникальному идентификатору.

Пример 1: Кэширование результатов вычислений (мемоизация)
from functools import lru_cache

# Встроенный декоратор для мемоизации
@lru_cache(maxsize=128)
def fibonacci(n):
    """Вычисление числа Фибоначчи с кэшированием"""
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# Ручная реализация мемоизации
def memoize(func):
    """Декоратор для мемоизации функции"""
    cache = {}

    def wrapper(*args):
        if args not in cache:
            cache[args] = func(*args)
        return cache[args]

    return wrapper

@memoize
def factorial(n):
    """Вычисление факториала с мемоизацией"""
    if n == 0:
        return 1
    return n * factorial(n-1)

# Тестирование
print("Числа Фибоначчи:")
for i in range(10):
    print(f"fib({i}) = {fibonacci(i)}")

print("\nФакториалы:")
for i in range(10):
    print(f"{i}! = {factorial(i)}")

# Практическое применение: кэширование запросов к API
import time

class APICache:
    """Простой кэш для API запросов"""
    def __init__(self, ttl=3600):  # TTL = 1 час
        self.cache = {}
        self.ttl = ttl

    def get(self, key):
        """Получение значения из кэша"""
        if key in self.cache:
            value, timestamp = self.cache[key]
            if time.time() - timestamp < self.ttl:
                return value
            else:
                # Удаляем просроченный элемент
                del self.cache[key]
        return None

    def set(self, key, value):
        """Сохранение значения в кэш"""
        self.cache[key] = (value, time.time())

    def clear(self):
        """Очистка кэша"""
        self.cache.clear()

# Использование
cache = APICache()
cache.set("users/123", {"name": "Alice", "age": 25})
print(f"\nИз кэша: {cache.get('users/123')}")
Пример 2: Конфигурация приложения
class Config:
    """Класс для управления конфигурацией приложения"""

    def __init__(self, default_config=None):
        self._config = default_config or {}
        self._overrides = {}

    def set(self, key, value):
        """Установка значения конфигурации"""
        keys = key.split('.')
        current = self._overrides

        for k in keys[:-1]:
            if k not in current:
                current[k] = {}
            current = current[k]

        current[keys[-1]] = value

    def get(self, key, default=None):
        """Получение значения конфигурации"""
        keys = key.split('.')

        # Сначала ищем в переопределениях
        value = self._traverse_dict(self._overrides, keys)
        if value is not None:
            return value

        # Затем в дефолтной конфигурации
        value = self._traverse_dict(self._config, keys)
        if value is not None:
            return value

        return default

    def _traverse_dict(self, d, keys):
        """Рекурсивный обход словаря по ключам"""
        if not keys:
            return d

        key = keys[0]
        if isinstance(d, dict) and key in d:
            return self._traverse_dict(d[key], keys[1:])

        return None

    def to_dict(self):
        """Возвращает полную конфигурацию как словарь"""
        result = self._deep_merge(self._config.copy(), self._overrides)
        return result

    def _deep_merge(self, base, override):
        """Глубокое объединение словарей"""
        for key, value in override.items():
            if key in base and isinstance(base[key], dict) and isinstance(value, dict):
                base[key] = self._deep_merge(base[key], value)
            else:
                base[key] = value
        return base

# Использование

    "database": {
        "host": "localhost",
        "port": 5432,
        "name": "myapp"
    },
    "server": {
        "host": "0.0.0.0",
        "port": 8000
    }
})

Частые ошибки и лучшие практики
Ошибка 1: Использование изменяемых объектов как ключей
# НЕПРАВИЛЬНО
my_dict = {}
my_dict[[1, 2, 3]] = "value"  # TypeError: unhashable type: 'list'
my_dict[{"key": "value"}] = "value"  # TypeError: unhashable type: 'dict'

# ПРАВИЛЬНО
my_dict = {}
my_dict[(1, 2, 3)] = "value"  # Кортеж можно использовать как ключ
my_dict[frozenset([1, 2, 3])] = "value"  # frozenset тоже можно
my_dict["ключ-строка"] = "value"  # Строки - отличные ключи
Ошибка 2: Модификация словаря во время итерации
# НЕПРАВИЛЬНО
my_dict = {'a': 1, 'b': 2, 'c': 3, 'd': 4}
for key in my_dict:
    if my_dict[key] % 2 == 0:
        del my_dict[key]  # RuntimeError: dictionary changed size during iteration

# ПРАВИЛЬНО
my_dict = {'a': 1, 'b': 2, 'c': 3, 'd': 4}
# Вариант 1: Итерируем по копии ключей
for key in list(my_dict.keys()):
    if my_dict[key] % 2 == 0:
        del my_dict[key]

# Вариант 2: Используем генератор словаря
my_dict = {k: v for k, v in my_dict.items() if v % 2 != 0}

Помните: Начиная с Python 3.7, словари сохраняют порядок вставки элементов. Используйте OrderedDict только если нужны специфические операции (move_to_end, popitem(last=False)).
Сравнение с другими структурами данных
Когда использовать словари:
  • Нужен быстрый доступ к данным по уникальному ключу
  • Данные имеют естественную структуру "ключ-значение"
  • Нужно агрегировать или группировать данные
  • Работаете с конфигурациями или настройками
  • Реализуете кэширование или мемоизацию
Золотые правила работы со словарями:
1. Используйте dict.get(key, default) для безопасного доступа
2. Используйте dict.items() для итерации по парам ключ-значение
3. Используйте генераторы словарей для создания словарей
4. Используйте collections.defaultdict когда нужны значения по умолчанию
5. Используйте collections.Counter для подсчета элементов
