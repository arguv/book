Генераторы (yield)

Память-эффективная обработка данных

Генератор — это специальный тип итератора в Python, который позволяет создавать последовательность значений лениво (lazy evaluation).

Вместо того чтобы вычислять все значения сразу и хранить их в памяти, генератор вычисляет значения по одному — когда они нужны.

Ключевое слово yield

yield используется внутри функции, чтобы вернуть значение и сохранить состояние функции.

Когда функция вызывается снова, выполнение продолжается с того места, где был yield.

Почему генераторы важны

  • Экономят память
  • Работают с огромными потоками данных
  • Используются в Data Engineering и Machine Learning
  • Подходят для обработки файлов и сетевых потоков

Обычная функция vs генератор


# обычная функция
def numbers():
    return [1,2,3]

print(numbers())

# генератор
def numbers_gen():
    yield 1
    yield 2
    yield 3

for n in numbers_gen():
    print(n)
Функция с yield автоматически становится генератором.

Как работает yield


def counter():

    print("start")

    yield 1

    print("middle")

    yield 2

    print("end")

    yield 3


g = counter()

print(next(g))
print(next(g))
print(next(g))

Каждый вызов next() продолжает выполнение функции.

Generator Expression

Генераторы можно создавать кратко, как list comprehension.


# list comprehension
numbers = [x*x for x in range(5)]

# generator expression
numbers_gen = (x*x for x in range(5))

for n in numbers_gen:
    print(n)

Память: генератор vs список

Тип Память Скорость
List Все данные сразу Быстрее доступ
Generator По одному элементу Экономит память 

import sys

list_obj = [x for x in range(1000000)]
gen_obj = (x for x in range(1000000))

print(sys.getsizeof(list_obj))
print(sys.getsizeof(gen_obj))

yield from

Позволяет генератору делегировать работу другому генератору.


def generator1():
    yield 1
    yield 2

def generator2():
    yield from generator1()
    yield 3

for x in generator2():
    print(x)

Методы генераторов


g = generator()

next(g)

g.send(value)

g.throw(Exception)

g.close()
  • next() — получить следующее значение
  • send() — отправить значение в генератор
  • throw() — бросить исключение
  • close() — остановить генератор

send() пример


def echo():

    value = yield

    while True:

        value = yield value


g = echo()

next(g)

print(g.send("hello"))
print(g.send("world"))

Практические применения

Чтение огромных файлов


def read_file(path):

    with open(path) as f:

        for line in f:

            yield line


for line in read_file("big_file.txt"):

    process(line)

Бесконечные последовательности


def infinite_numbers():

    n = 0

    while True:

        yield n

        n += 1

Генераторы vs Итераторы

Характеристика Iterator Generator
Создание class + __iter__ + __next__ yield
Сложность сложно очень просто
Использование редко очень часто

Частые ошибки

Ошибка 1

Попытка использовать генератор повторно.


g = (x for x in range(3))

list(g)

list(g)  # пусто

Ошибка 2

Забыть вызвать next() перед send()

  • Используйте генераторы для потоковой обработки
