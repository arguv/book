LLM — Large Language Models

Полное руководство для AI / ML / Data Engineers

Что такое LLM

LLM (Large Language Model) — это нейронная сеть огромного размера, обученная на больших объемах текстовых данных для понимания, генерации и анализа естественного языка.

Основная идея

LLM предсказывает следующее слово (token) в последовательности.

Пример: 

Input: "Machine learning is"
Prediction: "a", "the", "an"

LLM используется для:

  • чат-ботов
  • генерации текста
  • переводов
  • анализа документов
  • написания кода
  • поиска знаний

Основные компоненты LLM

  • Transformer architecture
  • Tokenization
  • Embeddings
  • Self-Attention
  • Feed Forward layers

Transformer Architecture

Большинство LLM построены на архитектуре Transformer.

Она была предложена в 2017 году в статье:

"Attention Is All You Need"

Основные элементы

  • Embedding Layer
  • Attention Layers
  • Feed Forward Networks
  • Layer Normalization

Tokenization

LLM не работает напрямую с текстом. Он работает с tokens.

Token — это часть слова или символ. 

Text:

Machine learning is powerful


Tokens:

["Machine", "learning", "is", "powerful"]

Популярные tokenizers:

  • BPE (Byte Pair Encoding)
  • WordPiece
  • SentencePiece

Embeddings

Embeddings — это числовое представление слов.

Каждое слово превращается в вектор. 


import numpy as np

word_vector = np.array([0.23, 0.11, -0.77, 0.91])

Embeddings позволяют модели понимать смысл слов.

Self Attention

Self-attention позволяет модели понимать контекст слов.

Пример: 

"The animal didn't cross the street because it was too tired."

Модель понимает, что it = animal.

Обучение LLM

Этап 1 — Pretraining

Модель обучается на огромных текстовых данных.

  • Books
  • Wikipedia
  • Web pages
  • Code

Этап 2 — Fine-tuning

Модель обучается на конкретных задачах.

Python пример использования LLM


from transformers import pipeline

generator = pipeline("text-generation")

result = generator(
"Artificial intelligence is",
max_length=20
)

print(result)

Prompt Engineering

Prompt — это инструкция для модели. 


Prompt:

Explain quantum physics for a child.

Хороший prompt сильно влияет на результат.

RAG — Retrieval Augmented Generation

RAG — это техника, которая позволяет LLM использовать внешние данные.
