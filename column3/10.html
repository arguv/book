Контекстные Менеджеры (with)

Контекстные менеджеры (Context Managers) в Python используются для автоматического управления ресурсами — например:

  • файлы
  • соединения с базой данных
  • сетевые соединения
  • блокировки потоков
  • временные изменения состояния
Главная идея: Python гарантирует, что ресурсы будут корректно освобождены.

Что такое оператор with

Оператор with создает управляемый блок выполнения. 

with expression as variable:
    block
Python автоматически вызывает: 1. `__enter__()` — при входе 2. `__exit__()` — при выходе

Самый распространенный пример — работа с файлами

with open("data.txt") as file:
    data = file.read()
    print(data)

# файл автоматически закрывается
Без `with`: 
file = open("data.txt")

try:
    data = file.read()
finally:
    file.close()
`with` заменяет try/finally и делает код безопаснее.

Как работает контекстный менеджер

Контекстный менеджер — это объект, имеющий методы:
  • __enter__()
  • __exit__()
class MyContext:

    def __enter__(self):
        print("Entering")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        print("Exiting")


with MyContext():
    print("Inside block")
Результат: 
class AsyncContext:

    async def __aenter__(self):
        print("Async enter")

    async def __aexit__(self, exc_type, exc, tb):
        print("Async exit")


async with AsyncContext():
    pass

Где используются контекстные менеджеры

  • работа с файлами
  • database connections
  • thread locks
  • network sockets
  • temporary environment settings
  • transactions

Сравнение способов

Метод Описание
try/finally ручное управление ресурсами
with автоматическое управление
@contextmanager простой способ создания менеджера
async with для асинхронного кода

Частые ошибки

Ошибка 1 Забыли вернуть объект из `__enter__`
Ошибка 2 Неправильная обработка исключений.
Ошибка 3 Использование ресурса вне блока `with`.

Лучшие практики

Всегда используйте `with` при работе с файлами.
Используйте `contextlib` для простых менеджеров.
Не подавляйте исключения без причины.

Ключевые выводы

  • Контекстные менеджеры управляют ресурсами
  • Они реализуются через `__enter__` и `__exit__`
  • `with` автоматически закрывает ресурсы
  • `contextlib` позволяет создавать их проще
  • Есть синхронные и асинхронные менеджеры
