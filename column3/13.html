Dataclasses

Современный способ создания классов для хранения данных

Dataclasses — это специальный механизм Python, добавленный в версии Python 3.7, который упрощает создание классов, предназначенных в основном для хранения данных.

Что делает dataclass?

Декоратор @dataclass автоматически генерирует:

  • __init__()
  • __repr__()
  • __eq__()
  • __hash__() (опционально)
  • __order__() (если нужно)

Почему появились Dataclasses

До появления dataclasses программисты писали много шаблонного кода.

Без dataclass

class Person:

    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __repr__(self):
        return f"Person(name={self.name}, age={self.age})"

С dataclass

from dataclasses import dataclass

@dataclass
class Person:
    name: str
    age: int
Dataclass автоматически создаст __init__, __repr__ и __eq__.

Основной синтаксис

from dataclasses import dataclass

@dataclass
class User:

    id: int
    name: str
    email: str

Создание объекта:

user = User(1, "Alice", "alice@mail.com")

print(user)

Типы полей

Dataclasses используют type hints.

@dataclass
class Product:

    id: int
    name: str
    price: float
    in_stock: bool
Типы не обязательны, но strongly recommended.

Значения по умолчанию

@dataclass
class User:

    name: str
    age: int = 18

Теперь можно создать:

user = User("Alice")
print(user.age)

field()

Функция field() позволяет настраивать поля.

from dataclasses import dataclass, field

@dataclass
class Order:

    id: int
    items: list = field(default_factory=list)
default_factory используется для изменяемых типов (list, dict, set).

Метод __post_init__

Позволяет выполнять дополнительную логику после создания объекта.

@dataclass
class Rectangle:

    width: int
    height: int
    area: int = 0

    def __post_init__(self):
        self.area = self.width * self.height

Frozen Dataclasses

Позволяет создать immutable объект.

@dataclass(frozen=True)
class Point:

    x: int
    y: int
Теперь нельзя изменить значения после создания объекта.

Ordering

Можно автоматически добавить операции сравнения.

@dataclass(order=True)
class Player:

    score: int
    name: str

Теперь можно:

p1 = Player(10,"Alice")
p2 = Player(20,"Bob")

print(p1 < p2)

Dataclass vs обычный класс

Функция Обычный класс Dataclass
__init__ Пишем вручную Создается автоматически
__repr__ Пишем вручную Автоматически
__eq__ Пишем вручную Автоматически
Boilerplate код Много Минимум

Полезные функции dataclasses

from dataclasses import asdict

user = User(1,"Alice","mail")

print(asdict(user))

Результат:

{'id':1,'name':'Alice','email':'mail'}

Еще функции

  • asdict()
  • astuple()
  • replace()
  • fields()
  • is_dataclass()

Практические применения

  • DTO (Data Transfer Objects)
  • API модели
  • ML data structures
  • configuration objects
  • ORM-like models

Лучшие практики

  • Используйте type hints
  • Используйте frozen=True для immutable объектов
  • Используйте default_factory для list/dict
  • Не злоупотребляйте логикой внутри dataclass

Частые ошибки

Ошибка с изменяемыми значениями:

@dataclass
class Bad:

    items: list = []

Правильно:

@dataclass
class Good:

    items: list = field(default_factory=list)

Заключение

Dataclasses — один из самых удобных инструментов Python.

  • меньше boilerplate кода
  • лучше читаемость
  • автоматическая генерация методов
  • идеально для моделей данных
