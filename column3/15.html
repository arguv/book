Линейная алгебра для Python и Machine Learning

Основы для нейронных сетей, Data Science и AI

1. Числа, векторы и матрицы

Линейная алгебра — фундамент Machine Learning.

Она используется в:
  • нейронных сетях
  • обработке изображений
  • обработке текста
  • PCA (уменьшение размерности)
  • рекомендательных системах
Объект Описание Пример
Число Обычное значение 5
Вектор 1D массив [1,2,3]
Матрица 2D массив [[1,2],[3,4]]

2. Векторы (1D массивы)

Вектор — это набор чисел.


import numpy as np

v = np.array([1,2,3])

print(v)
Результат 

[1 2 3]
В ML векторы используются для: - признаков (features) - embeddings - входных данных нейронных сетей

3. Матрицы (2D массивы)


import numpy as np

A = np.array([
[1,2],
[3,4]
])

print(A)
Результат 

[[1 2]
 [3 4]]

Матрица используется для хранения большого количества данных.

Пример: | объект | height | weight | |------|------|------| |1|170|65| |2|180|80|

4. Операции с матрицами

Сложение


A = np.array([[1,2],[3,4]])
B = np.array([[5,6],[7,8]])

print(A + B)
Результат 

[[ 6  8]
 [10 12]]

Транспонирование


print(A.T)
Результат 

[[1 3]
 [2 4]]

5. Скалярное произведение (Dot Product)


v1 = np.array([1,2,3])
v2 = np.array([4,5,6])

print(np.dot(v1,v2))
Результат 

32
Расчет: 14 + 25 + 3*6 = 32
Dot product используется в: - нейронных сетях - рекомендациях - similarity search

6. Умножение матриц


A = np.array([
[1,2],
[3,4]
])

B = np.array([
[5,6],
[7,8]
])

print(A @ B)
Результат 

[[19 22]
 [43 50]]
Расчет: [15 + 27 , 16 + 28] [35 + 47 , 36 + 48]
Это **основная операция нейронных сетей**. Output = Weights @ Inputs + Bias

7. Определитель (Determinant)

Определитель показывает: - можно ли обратить матрицу - масштаб преобразования 

A = np.array([
[1,2],
[3,4]
])

print(np.linalg.det(A))
Результат 

-2.0

8. Обратная матрица

Используется для решения систем уравнений. 

A = np.array([
[1,2],
[3,4]
])

print(np.linalg.inv(A))
Результат 

[[-2.   1. ]
 [ 1.5 -0.5]]

9. Собственные значения и векторы

Используются в: - PCA - спектральных методах - компьютерном зрении 

A = np.array([
[2,0],
[0,3]
])

values, vectors = np.linalg.eig(A)

print(values)
print(vectors)
Результат 

[2. 3.]

[[1. 0.]
 [0. 1.]]

10. PCA (уменьшение размерности)

PCA использует: - eigenvalues - eigenvectors для поиска **главных направлений данных**. Пример: 100 признаков → 2 признака. Это используется в: - ML - визуализации данных - compression

Заключение

Ключевые элементы линейной алгебры для ML:
  • Векторы — представление данных
  • Матрицы — хранение dataset
  • Dot product — similarity
  • Matrix multiplication — нейронные сети
  • Determinant — свойства матриц
  • Inverse matrix — решение уравнений
  • Eigenvalues / eigenvectors — PCA
Если вы хотите стать **ML Engineer или Data Engineer**, эти операции используются **ежедневно в TensorFlow, PyTorch и NumPy**.
