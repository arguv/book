Исключения

try / except / finally

Исключения (Exceptions) — это механизм обработки ошибок во время выполнения программы. Когда происходит ошибка, Python создает объект исключения.

Зачем нужны исключения?

  • обработка ошибок без падения программы
  • контроль выполнения кода
  • обработка нестандартных ситуаций
  • надежность и безопасность программ

Базовый синтаксис try / except

try:
    # код, где может возникнуть ошибка

except:
    # обработка ошибки

Простой пример

try:
    result = 10 / 0

except:
    print("Произошла ошибка!")

Обработка конкретных исключений

try:
    x = int("abc")

except ValueError:
    print("Ошибка преобразования числа")
Лучше всегда указывать конкретный тип исключения.

Несколько except

try:
    x = int(input())
    y = 10 / x

except ValueError:
    print("Нужно ввести число")

except ZeroDivisionError:
    print("Деление на ноль")

except как переменная

try:
    5 / 0

except ZeroDivisionError as e:
    print("Ошибка:", e)

Переменная e содержит объект ошибки.

Блок finally

Блок finally выполняется ВСЕГДА. 

try:
    x = 10 / 0

except:
    print("Ошибка")

finally:
    print("Этот код выполнится всегда")

Полная структура try

try:
    code

except ErrorType:
    handler

else:
    code_if_no_error

finally:
    always_run

else блок

else выполняется только если ошибок не произошло. 

try:
    x = 10 / 2

except:
    print("Ошибка")

else:
    print("Все прошло успешно")

raise — создание исключения

def check_age(age):

    if age < 18:
        raise ValueError("Возраст должен быть 18+")

Создание собственного исключения

class MyError(Exception):
    pass


raise MyError("Моя ошибка")

Основные типы исключений Python

Исключение Описание
ValueError Неверное значение
TypeError Неверный тип данных
IndexError Выход за границы списка
KeyError Нет ключа в словаре
ZeroDivisionError Деление на ноль
FileNotFoundError Файл не найден

Лучшие практики

  • ловите конкретные ошибки
  • не используйте пустой except
  • используйте finally для закрытия ресурсов
  • используйте raise для собственных ошибок

Плохая практика

try:
    code

except:
    pass

Когда использовать try/except

  • работа с файлами
  • сетевые запросы
  • обработка пользовательского ввода
  • работа с базами данных
  • API вызовы

Заключение

  • try — код где может быть ошибка
  • except — обработка ошибки
  • else — если ошибки нет
  • finally — выполняется всегда
  • raise — создание исключения
