Prompt Engineering

Prompt Engineering is the process of writing clear, structured instructions to an AI model to get accurate, useful, and predictable results.

  • Role: Define who the AI should act as. Example: Act as a Senior PHP Engineer.
  • Task: Clearly explain what the AI should do. Example: Review my PHP code.
  • Context: Provide relevant background information. Example: Symfony 7, PHP 8.3, PostgreSQL.
  • Constraints: Define rules and limitations. Example: Do not change business logic.
  • Output Format: Specify how the AI should respond. Example: JSON, table, or code.
  • Zero-shot Prompting: Ask the AI to perform a task without examples.
  • One-shot / Few-shot Prompting: Provide one or several examples to guide the AI.
  • Prompt Chaining: Divide a complex task into smaller, connected steps.
  • Iterative Refinement: Improve the prompt based on the AI's previous responses.
  • Key Takeaway: Good prompt engineering means clearly defining the task, providing context, setting constraints, and evaluating the result.
Practical example
ROLE:
You are a Senior Backend Engineer.

TASK:
Review the following REST API implementation.

CONTEXT:
The application uses PHP 8.3, Symfony 7,
Doctrine ORM, and PostgreSQL.

CONSTRAINTS:
- Identify security and performance problems.
- Do not change business logic.
- Keep explanations short.

OUTPUT FORMAT:
Return a table with:
